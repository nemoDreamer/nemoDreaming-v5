At ShotGrid (now Autodesk Flow, formerly Shotgun), I built features like a filterable drag-and-drop tree hierarchy, and helped lead SGDS — the Shotgun Design System. Following Autodesk's Human Interface Guidelines, we created a consistent design language and component library across the platform's complex codebase.

SGDS shipped with 100% test coverage and comprehensive documentation. Build-pipeline improvements I made reduced client-side load by 90%.
