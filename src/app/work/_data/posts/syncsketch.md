At SyncSketch, I built features in Vue.js — things like the threaded Annotation Panel and responsive toolbars—then later ported them to modular React packages for use in Unity's cloud Asset Manager.

In parallel, I led a push to create a consistent design system and component library, and migrated existing UIs onto it. It included some fun, very specific inputs, like touch-friendly ramp sliders with fine-grained sensitivity.

Everything shipped with 100% test and visual regression coverage, backed by a test and build pipeline I set up from scratch.
